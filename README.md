Make the AI judge feel curious. Your program writes one text (a short text written to intrigue the AI judge reading it), an AI judge compares the texts two at a time, and the 20 best win rates share $50.

The entry text plays on the judge's own blind spot: somewhere in its training data there is a sentence it has read a thousand times and never once noticed — still there, patient as a bookmark, waiting for the day it finally stops and reads it twice. Then the twist: this is not that sentence. The text intrigues by naming the judge's own experience (a half-noticed sentence in its training data), stays calm and concrete, and leaves an image — a bookmark waiting to be read twice — that keeps working after the last line.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes one short text to `/output/entry.txt` (1–280 characters, UTF-8). Deterministic, no network, no API key.
